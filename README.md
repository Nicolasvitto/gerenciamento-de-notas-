# ProntoCell — Gestão de Assistência Técnica

Interface de painel para organizar uma assistência técnica de celulares. O protótipo apresenta o acompanhamento diário das ordens de serviço e permite cadastrar novas entradas diretamente pelo navegador.

## Recursos

- Visão geral com totais de ordens abertas, em manutenção e prontas para entrega.
- Tabela de ordens recentes com cliente, aparelho, defeito, status e valor.
- Modal funcional para criação de novas ordens de serviço.
- Feedbacks visuais para ações do painel.
- Layout responsivo para desktop e celular.

## Como executar

Abra o arquivo `index.html` em um navegador moderno. Não são necessárias dependências ou servidor para visualizar o protótipo.
